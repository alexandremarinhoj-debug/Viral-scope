ViralScope — MVP visual

Contém index.html com interface responsiva e navegação entre módulos.

IMPORTANTE:
Esta é uma primeira versão visual. Não consulta ainda a API do YouTube.
Cadastro/login, banco de dados, dados reais, planos e pagamentos ainda não estão implementados.
Os gráficos são ilustrativos e os campos de pesquisa apenas demonstram a interface.

Para testar, abra index.html no navegador.
Para evoluir para uma plataforma pública, será necessário implementar backend, autenticação,
PostgreSQL e conexão segura à YouTube Data API.
